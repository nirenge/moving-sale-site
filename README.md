# אתר מכירת פריטים – מעבר דירה

אתר סטטי פשוט (HTML / CSS / JavaScript בלבד, ללא frameworks) להצגת פריטים למכירה עם יצירת קשר מהירה בוואטסאפ.

## מבנה הפרויקט

```
moving-sale-site/
├── index.html          עמוד המכירה הראשי (זה מה ששולחים בקישור)
├── admin.html           עמוד ניהול המוצרים
├── styles.css            כל העיצוב
├── js/
│   ├── config.js         הגדרות כלליות (מספר הוואטסאפ)
│   ├── products.js       *קובץ הנתונים* – רשימת כל המוצרים
│   ├── utils.js           פונקציות עזר משותפות
│   ├── lightbox.js         תצוגת תמונה מוגדלת (Lightbox) בעמוד המכירה
│   ├── app.js              לוגיקת עמוד המכירה
│   └── admin.js            לוגיקת עמוד הניהול
└── images/                תמונות המוצרים (כבר כוללות את התמונות שלך)
```

התמונות שלך מתיקיית `ForSale` כבר הועתקו ושובצו לפי הפריטים המתאימים (קומודה, כורסאות,
ספה, שולחן, מיקרוגל, כיסא אוכל, שעון קיר, כיסא שחור, תמונות קיר, מדפים).

**⚠️ שימו לב:** בכל המוצרים שדות המחיר, המידות והתאריך מולאו כברירת מחדל בתור "לעדכן" —
אני לא יכולתי לדעת את המחירים/המידות המדויקים מהתמונות. יש להיכנס ל-`admin.html` ולמלא
ערכים אמיתיים **לפני** ששולחים את הקישור הלאה.

## שינוי מספר הוואטסאפ

נמצא **במקום אחד בלבד**: [js/config.js](js/config.js)

```js
const CONFIG = {
  whatsappPhone: "972501234567", // להחליף למספר האמיתי שלך
};
```

הפורמט: קידומת מדינה בלי "+" ובלי "0" מוביל. למשל מספר `050-1234567` הופך ל-`972501234567`.

## איך מוסיפים מוצר חדש

**דרך admin.html (מומלץ – בלי לגעת בקוד):**
1. פתחו את `admin.html` בדפדפן.
2. לחצו על "**+ הוספת מוצר חדש**".
3. מלאו את השדות (שם, מחיר, מידות, מצב, תאריך זמינות, נתיב לתמונה).
4. לחצו על "**⬇️ הורדת קובץ products.js מעודכן**" והחליפו את הקובץ ב-`js/products.js`.
5. העלו את השינויים לאתר (ראו סעיף פרסום למטה).

**ידנית (עריכת קובץ נתונים):**
פתחו את [js/products.js](js/products.js) והוסיפו אובייקט חדש למערך `PRODUCTS`, לדוגמה:

```js
{
  id: 11,
  name: "כיסא נדנדה",
  price: "300 ₪",
  dimensions: "70x80 ס״מ",
  condition: "מצב מעולה",
  availableDate: "מיידי",
  image: "images/my-chair.jpg",
  sold: false,
},
```

אם מוסיפים תמונה חדשה, יש להעתיק את קובץ התמונה לתיקיית `images/` ולוודא שהנתיב ב-`image` תואם.

## תצוגת תמונה מוגדלת (Lightbox) ותמונות נוספות

לחיצה על תמונת מוצר בעמוד המכירה פותחת תצוגה מוגדלת (מסך מלא). אם למוצר יש כמה
תמונות, אפשר לדפדף ביניהן בחצים, בנקודות התחתונות, בהחלקת אצבע (במובייל) או במקשי
החצים במקלדת. סגירה: כפתור ה-✕, מקש Escape, או לחיצה מחוץ לתמונה.

**איך מוסיפים תמונות נוספות לאותו מוצר:**

- **דרך admin.html (מומלץ):** בשדה "תמונות נוספות לאותו פריט" הקלידו את שמות הקבצים
  הנוספים מופרדים בפסיק, למשל: `images/sofa-2.jpg, images/sofa-3.jpg` (יש להעלות את
  קובצי התמונות עצמם לתיקיית `images/` באותו אופן שמעלים כל תמונה אחרת).
- **ידנית:** בקובץ `js/products.js` הוסיפו למוצר שדה `images` עם מערך של כל הנתיבים,
  לדוגמה:

```js
image: "images/sofa.jpg",
images: ["images/sofa.jpg", "images/sofa-2.jpg", "images/sofa-3.jpg"],
```

אם לא מגדירים `images`, המוצר פשוט יציג את התמונה הבודדת שבשדה `image` — אין צורך
לשנות מוצרים קיימים שאין להם כמה תמונות.

## איך מסמנים מוצר כ״נמכר״

**דרך admin.html:** סמנו את התיבה "**סומן כנמכר**" ליד המוצר, ואז ייצאו והחליפו את `products.js` כמו למעלה.

**ידנית:** שנו את השדה `sold` של המוצר ל-`true` בקובץ `js/products.js`.

כאשר מוצר מסומן כנמכר:
- הכרטיס נשאר בעמוד אך נראה מעומעם.
- מופיעה שכבת "נמכר" מעל התמונה.
- כפתור הוואטסאפ הופך לכפתור מושבת עם הכיתוב "הפריט נמכר".

## הערה חשובה על עמוד הניהול

מדובר באתר **סטטי** ללא שרת/מסד נתונים. עמוד `admin.html` שומר את השינויים
בדפדפן בלבד (localStorage) כטיוטה לתצוגה מקדימה. כדי שהשינויים יהיו זמינים לכל
מי שנכנס לאתר, **חובה** לייצא את קובץ `products.js` המעודכן (כפתור ההורדה),
להחליף איתו את הקובץ הקיים בפרויקט, ולפרסם מחדש (git push / גרירה מחדש ל-Netlify).

## איך מעלים את האתר לאוויר

### אפשרות 1: GitHub Pages
1. יוצרים repository חדש ב-GitHub ומעלים אליו את כל תוכן התיקייה הזו.
2. נכנסים ל-Settings → Pages.
3. תחת "Source" בוחרים את הברנץ' (למשל `main`) ותיקיית השורש `/`.
4. שומרים — האתר יהיה זמין בכתובת `https://<username>.github.io/<repo-name>/`.
5. כל עדכון (כולל `products.js` חדש) דורש `git add`, `git commit`, `git push`.

```bash
git init
git add .
git commit -m "אתר מכירת פריטים"
git branch -M main
git remote add origin https://github.com/<username>/<repo-name>.git
git push -u origin main
```

### אפשרות 2: Netlify (הכי פשוט, בלי git)
1. נכנסים ל-[netlify.com](https://www.netlify.com) ונרשמים.
2. בעמוד הבית גוררים את **כל תיקיית הפרויקט** לתוך אזור ה-Drag & Drop ("Deploys").
3. Netlify מפרסם אתר מיידית עם קישור אקראי (אפשר לשנות שם בהגדרות).
4. לעדכון: אחרי שינוי (למשל `products.js` חדש), גוררים שוב את התיקייה לאותו פרויקט.

### אפשרות 3: כל אחסון סטטי אחר
מכיוון שזה HTML/CSS/JS טהור בלי build step, אפשר להעלות את התיקייה כמות שהיא
לכל שירות אחסון קבצים סטטי (Vercel, Firebase Hosting, S3, ועוד).

## בדיקה מקומית לפני פרסום

פותחים את `index.html` ישירות בדפדפן (לחיצה כפולה על הקובץ), או מריצים שרת מקומי פשוט:

```bash
npx serve .
```
